01

What the stack is

Pi is a terminal coding agent. It is one CLI binary plus three kinds of plug-in: packages (installed with pi install), extensions (TypeScript files that hook into the agent loop), and skills (folders of instructions the model loads on demand). A single rules file, AGENTS.md, governs behaviour.

Agent core

pi 1.4.0 on Node 24. Bundled coding system prompt, tool loop, session store.

Policy layer

AGENTS.md (361 lines) plus decision-gates.ts. Gates decide closed questions in code, with zero model calls.

Capability layer

12 packages: memory, subagents, context compression, web search, todos, permission system.

Model layer

18 OpenAI/Anthropic-compatible gateways, 129 models, keyed by environment variables.

The one thing that must not break: the gate denylist, the secrets rule, and the no-local-install rule. They are the difference between this working on a phone and it working anywhere. On a laptop the no-install rule can be relaxed — the gates do not have to be.

The rules file

~/.pi/agent/AGENTS.md loads into every session on the machine. A project-level AGENTS.md overrides it. It is 361 lines and organised in ten numbered parts. The parts that matter most when porting:

PartWhat it enforcesKeep on laptop?
§0 InstallsNever install anything without asking in that conversation. Permission is per-install.Yes, verbatim
§0B SecretsNever decrypt, read, list or print a secret. Vault reads are user-run only.Yes, verbatim
§0C StyleAnswer first, short sentences, plain words, no filler vocabulary.Yes, verbatim
§1 ProtocolsIntent routing, CRISP-LO pre-flight, superpowers workflow.Yes
§3B No buildsNo local npm install, no bundlers. Build in CI instead.Relax — laptop can build
§4E GatesWhich decision gates exist and which are enforcing.Yes
§5 UI gatePick a visual direction before writing styling code.Yes
§6 BrowserSix breakpoints, mobile first, 44px tap targets.Yes
§9 DoneNine required checks before claiming completion.Yes
§10 Anti-passNo "LGTM" without command output and a lint pass.Yes, verbatim
Local wisdom you should not carry over: §3 lists tools that do not exist on this phone (rtk, cloudflared, the Supabase CLI). On a laptop those tools do exist. Rewrite that table rather than copying it — otherwise the agent will refuse to use things that work.

Keys are not in the file

The published models.sanitized.json has every apiKey replaced with an environment placeholder such as $DOLPHIN_API_KEY or $OPENROUTER_API_KEY. Pi resolves $NAME and ${NAME} at request time, so you only need to export the variables in your shell profile.

Do not copy auth.json or mcp-auth.json. Those hold live credentials in this machine's format. On the laptop, run pi auth login or export the env vars fresh. Copying a credential file across machines is how keys leak.

Thinking levels map per provider, because gateways name them differently: off → none, minimal/low → low, high → high, xhigh/max → max. Check each provider's thinkingLevelMap before switching models, or the agent may silently run at the wrong effort.

06

Extensions

Four TypeScript files plus one permission config, all under ~/.pi/agent/extensions/. They need no build step: pi loads them directly.

decision-gates.ts — 15.5 KB

The most important file. It runs inline on tool events with zero model calls and zero network calls.

GateWhenWhat it does
G1 safetyevery bash callDenylist: force-push, push to main, git merge, --hard reset, recursive delete of home/Termux root, mkfs, dd, env dumps, .env reads, vault decryption, inline curl credentials, Supabase CLI.
G4 reviewturn end + on demandTracks written paths, appends one advisory line: forced / normal / inline review, plus security-scan and browser-review flags.
G6 loop capon tool failureCounts identical failures. Third one injects "stop retrying, change approach". Hard cap in code.
G8 tieron demandClassifies a task as trivial / standard / hard.
G9 scopeon demandFlags node_modules, lockfiles, dist, build output in a changed-file list.
G12 success capon successSecond identical green command injects "already verified — report and stop".

Two bugs fixed in this copy are worth preserving: the forced-path regex is /(^|\/)(delete|destroy|drop)([^a-z0-9]|$)/i so dropdown.tsx is not mistaken for a deletion path, and the Termux-root rule is anchored rather than prefix-matching.

notify.ts — Android only

Raises a real Android notification plus a vibration when a turn finishes, so backgrounded Termux still tells you. Every call is wrapped in timeout -k 1 4 with a 5-second minimum gap, because a frozen Termux:API app otherwise blocks forever. Delete this file on a laptop — it calls termux-notification, which does not exist there.

timing.ts — 6.5 KB

Measures time-to-first-token, total time, and output tokens per second for every response. Shows a one-line marker under each reply and a table at /timing. Pure local arithmetic.

kiosapi-guard.ts — rate pacing

Enforces 650 ms between requests to the kiosapi provider to avoid HTTP 429 on the free tier, and warns on 429/5xx. Only activates when the active model provider is kiosapi.

pi-permission-system/config.json

Second, independent policy layer. Default allow, then explicit denies.

path:  *.env, *.env.*, .dev.vars, auth.json, */.ssh/*,
       */.infisical/*, *.pem, *.key          → deny
bash:  rm -rf / | ~ | ~/* | /data/data/com.termux
       sudo *, git push --force*, git push * main
       git merge *, infisical secrets|export|run
       env, printenv*, export -p, age -d*, gpg -d*
       npm install|ci|run build, next build, vite build
       wrangler dev, supabase start           → deny
       npx *                                  → ask
Known over-reach: the rm -rf /* style rules also match relative paths, so cd dir && rm -rf sub can be denied. Keep it in mind rather than fighting it.

Rebuild it on the laptop

Download the bundle from the file list at the bottom of this page, then:

  1. Unpack and read the installer

    The script is 8 idempotent steps. Read it before running — it does not touch anything outside ~/.pi, ~/.agents and ~/superpowers.

    unzip pi-workflow-bundle.zip -d pi-workflow
less pi-workflow/install.sh
  2. Run it
    bash pi-workflow/install.sh

    Existing files are never overwritten. An existing models.json is backed up first.

  3. Give it keys

    Either export the provider variables, or let pi hold them.

    # option A — environment
echo 'export DOLPHIN_API_KEY=...' >> ~/.zshrc
echo 'export OPENROUTER_API_KEY=...' >> ~/.zshrc

# option B — stored credential
pi auth login openrouter
  4. Trim the phone-only parts
    rm ~/.pi/agent/extensions/notify.ts     # calls termux-notification
# in AGENTS.md: rewrite §3B and the §3 tool table for a machine that can build
  5. Verify once
    pi --version                       # 1.x
pi list | head -20                 # packages present
pi auth status                     # providers ready
# then inside pi:
/model                             # picker shows your models

    One pass is enough. Do not re-run the same check with a different command to be sure.

  6. Add the git guard

    Install a pre-commit hook so credentials never reach a commit:

    mkdir -p ~/.git-templates/hooks
printf '#!/bin/sh\ngitleaks protect --staged --redact\n' \
  > ~/.git-templates/hooks/pre-commit
chmod +x ~/.git-templates/hooks/pre-commit
git config --global init.templateDir ~/.git-templates
10

Port notes and traps

Do not copy these files

FileWhy
auth.jsonLive provider credentials.
mcp-auth.jsonOAuth tokens for Supabase/Context7.
models-store.json (505 KB)Cache of the pi.dev model catalog. Regenerates itself.
sessions/, pi-sessions/, missions/Conversation history. Large, personal, machine-specific.
memory/Personal notes. Copy deliberately if you want them, not as part of setup.
~/.herenow/credentialsPresent only if you signed in; treat as a secret.

Traps that cost time

  • MCP servers need a fresh login. mcp.json is just two URLs. Run pi mcp login supabase on the laptop; the OAuth flow opens a browser.
  • Extension API version mismatch. If a package upgrades past the extensions' expectations, decision-gates.ts fails to load. Check pi startup output for extension errors before blaming the gates.
  • Superpowers path is absolute in settings. This machine has "../../superpowers" relative to ~/.pi/agent. On a new machine, prefer pi install ~/superpowers so the path is rewritten correctly.
  • Thinking levels differ per gateway. A model set to high may run at low if the provider's thinkingLevelMap does not define it. Verify with /thinking.
  • kiosapi pacing is hardcoded at 650 ms. If you switch to a paid tier, raise or remove it in kiosapi-guard.ts.
  • Two policy layers overlap. The gates and the permission system both deny things. A command blocked by one is not necessarily blocked by the other, and the error text tells you which fired.

What gets better on a laptop

Local builds

§3B disappears. npm install, test suites, and bundlers all run locally, so the red-green loop is seconds instead of a CI round trip.

Real browser automation

Playwright replaces the chromium script. Six-breakpoint review becomes scripted rather than hand-driven.

Supabase CLI

A local Postgres stack replaces MCP branches for migration testing.

Cloud tunnels

cloudflared installs normally, so exposing a local port is one command.
